# Website Editing Guide

This website is a static GitHub Pages site. No build step is required.

## Common edits

- Change the site title and subtitle in each HTML file or edit the generation script if you keep it.
- Replace `assets/images/eao-profile.svg` with a real profile photo using the same filename.
- Replace `assets/images/site-icon.svg` with an approved institutional or lab mark if desired.
- Update `publications.html` when new papers are accepted.
- Replace placeholder resource files with real code, datasets, or lab documentation.

## Publishing with GitHub Pages

1. Create a GitHub repository.
2. Upload all files from the website folder to the repository root.
3. Go to Settings > Pages.
4. Select the main branch and the root folder.
5. Save and wait for GitHub to publish the site.
