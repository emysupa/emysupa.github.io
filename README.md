# Emmanuel A. Ogunniyi Academic Website

This repository contains a complete static academic website for GitHub Pages.

## Pages included

- `index.html` - home page
- `research.html` - research areas
- `publications.html` - searchable/filterable publication list
- `projects.html` - grants, contracts, and research projects
- `personnel.html` - principal investigator and selected mentorship
- `teaching.html` - teaching, training, and courses taught
- `resources.html` - repositories, downloads, and project resources
- `cv.html` - CV summary and embedded PDF
- `contact.html` - contact information and profiles
- `404.html` - custom not-found page

## Assets included

- `assets/files/Emmanuel_A_Ogunniyi_CV.pdf` - CV PDF
- `assets/files/selected_publications.bib` - starter BibTeX file
- `assets/files/student_research_ideas.md` - starter student project document
- `assets/files/website_editing_guide.md` - editing instructions
- `assets/images/` - SVG placeholders and research workflow figure
- `css/styles.css` - site styling
- `js/main.js` - active navigation, filters, copy citation buttons, year update

## Publishing

Upload the contents of this folder to the root of a GitHub repository. Then enable GitHub Pages in repository settings using the main branch and root folder.

## Customization notes

The website uses generic SVG placeholders rather than official university logos or a real portrait. Replace those files with approved images if desired.
